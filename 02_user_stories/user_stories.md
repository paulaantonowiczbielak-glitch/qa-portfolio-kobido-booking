# Historie użytkowników (User Stories)

## US01 - Rezerwacja masażu

Jako klient

chcę wybrać rodzaj masażu

aby zarezerwować usługę odpowiadającą moim potrzebom.

---

## US02 - Wybór terminu

Jako klient

chcę wybrać termin wizyty

aby dopasować go do swojego harmonogramu.

---

## US03 - Potwierdzenie wizyty

Jako klient

chcę otrzymać potwierdzenie rezerwacji

aby mieć pewność, że termin został zapisany.

---

## US04 - Anulowanie wizyty

Jako klient

chcę anulować wizytę

aby zwolnić termin, jeśli nie mogę przyjść.

---

## US05 - Zarządzanie rezerwacjami

Jako administrator

chcę widzieć wszystkie rezerwacje

aby zarządzać grafikiem salonu.
